# 참값 펌웨어 (ESP32)

지금 버전: **`node/` — USB 시리얼 버전 (node-2.0-usb)**
ESP32를 노트북에 USB로 꽂아 두면, 노트북 서버가 값을 받아 웹앱에 보여 줍니다. (WiFi로 Supabase에 올리는 부분은 다음 단계에서 더합니다)

지금 지원하는 센서 (`node/config.h`에서 켜고 끔)
| 센서 | 설정 | 기본 핀 |
|---|---|---|
| 온습도 A — **DHT11** (SHT31 납땜 전 임시) | `USE_DHT11_A 1` | `DHT_PIN 4` ← **꽂은 핀으로 바꾸세요** |
| 온습도 A·B — SHT31 (나중에) | `USE_SHT31_A`, `USE_SHT31_B` | SDA 21, SCL 22 |
| 토양수분 A·B (SEN0193) | `USE_SOIL_A`, `USE_SOIL_B` | 32, 33 |
| 로드셀 + HX711 | `USE_HX711` | DT 26, SCK 27 |
| 펌프 (DFR0457) | `USE_PUMP` | 25 |
| 12V 감지 / 누수 | `USE_V12_SENSE`, `USE_LEAK` | 34 / 35 (지금은 0) |

## 1. 처음 한 번: 라이브러리 설치 (Arduino IDE → 왼쪽 책 아이콘 "라이브러리 매니저")
| 검색어 | 고를 것 | 이 노트북 |
|---|---|---|
| `DHT sensor library` | 만든 사람 **Adafruit** | 이미 있음 |
| `Adafruit Unified Sensor` | Adafruit | 이미 있음 |
| `HX711` | 만든 사람 **Bogdan Necula** | **없음 → 설치** |

보드: 도구 → 보드 → esp32 → **ESP32 Dev Module** (esp32 보드 패키지 3.x, 이 노트북에 3.3.11 있음)

## 2. 올리기
1. Arduino IDE에서 `firmware/node/node.ino`를 연다 (`config.h`가 옆 탭에 같이 열린다).
2. `config.h`에서 **`DHT_PIN`을 DHT11을 꽂은 핀 번호로** 바꾼다. 토양·로드셀 핀이 다르면 그것도 바꾼다.
3. 도구 → 포트에서 ESP32 포트(COM 번호)를 고르고 **업로드(→ 버튼)**.
4. 확인: 시리얼 모니터를 **115200**으로 열면 5초마다 이런 줄이 나온다.
   ```
   {"t":"data","node":"Z1","ms":20111,"seq":4,"sht_a_ok":1,"temp_a":24.00,"rh_a":40.00,...,"weight_raw":94750,...}
   ```
5. **시리얼 모니터를 닫는다.** (열려 있으면 서버가 포트를 못 연다)

## 3. 앱에서 보기
터미널 두 개를 연다.
```bat
:: 터미널 1 — 서버 (ESP32 포트를 자동으로 찾는다)
cd server
run_server.bat --mode serial

:: 터미널 2 — 웹앱
cd web
npm run dev
```
브라우저에서 **http://localhost:5173** → 홈에 Z1 값이 5초마다 바뀐다.
- 온습도 B처럼 아직 안 단 센서는 "미설치"로 보인다.
- 로드셀은 보정 전이라 "raw 94,750 · 보정 전"처럼 원시값이 보인다.
- 펌웨어를 다시 올릴 때는 **서버(터미널 1)를 먼저 끈다** (Ctrl+C). 포트를 서버가 쥐고 있으면 업로드가 안 된다.

## 4. 보정 (지금은 명령으로, 보정 화면은 웹에 곧 생긴다)
보정값은 ESP32 안(NVS)에 저장돼 전원을 꺼도 남는다. 둘 중 편한 방법으로:
- **서버를 켜기 전에** Arduino 시리얼 모니터 입력칸에 명령을 친다 (줄 끝: "새 줄").
- 또는 서버가 켜진 상태에서 http://localhost:8000/docs → `POST /api/nodes/{node}/command` → node `Z1`, `{"cmd": "tare"}`처럼 보낸다.

| 하고 싶은 것 | 명령 | 순서 |
|---|---|---|
| 로드셀 영점 | `tare` | 판을 비우고 (약 2초) |
| 로드셀 배율 | `cal 500` | tare 다음, 500g짜리를 올리고 |
| 토양 A 공기 값 | `soilcal a air` | 센서를 공중에 들고 |
| 토양 A 물 값 | `soilcal a wet` | 경계선까지 물컵에 꽂고 |
| 토양 B | `soilcal b air` / `soilcal b wet` | 위와 같이 |
| 지금 설정 보기 | `info` | |
| 측정 주기 바꾸기 | `interval 10000` | 2000~600000 ms |
| 구역 이름 바꾸기 | `id z2` 다음 `reboot` | 보드마다 다르게 |

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 온습도 A가 `--` 이고 진단에 "응답 없음" | `DHT_PIN` 번호, DHT11의 VCC(3.3V)·GND·DATA 선 |
| 토양 값이 `--` | 그 센서의 mV가 150 미만(신호선 빠짐) 또는 3050 초과(GND 빠짐·단락) |
| 무게 raw가 안 바뀜 | HX711 DT·SCK 선, 로드셀 4선 |
| 서버가 "다른 프로그램이 포트를 쓰고 있어요" | Arduino 시리얼 모니터를 닫는다 |
| 서버가 포트를 못 찾음 | `run_server.bat --mode serial --port COM5` 처럼 직접 지정 |

## 확인한 것 / 못 한 것
- 이 노트북의 arduino-cli(ESP32 core 3.3.11, DHT 1.4.x, HX711 0.7.5)로 **컴파일 통과** (저장공간 24%).
- 펌웨어가 내보내는 것과 같은 형식의 줄로 서버·웹앱 표시를 확인했다.
- **실제 보드에 올려 본 것은 아니다** (하드웨어가 이 노트북에 없음).
