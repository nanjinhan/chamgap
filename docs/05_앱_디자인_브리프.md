# 참값(CHAMGAP) 앱·웹 디자인 브리프

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-10-24 |
| 이 문서의 역할 | 참값 웹앱을 **처음부터 다시 디자인**할 때 필요한 것을 한곳에 모은 것. 코드를 몰라도 이 문서만으로 화면을 그릴 수 있게 썼다 |
| 기준 문서 | 요구사항지시서 `docs/01_requirements.md` v2.0 (특히 4장 데이터, 6장 진단, 7장 안전, 8장 웹), 기존 와이어프레임 `docs/design/wireframe/` |
| 읽는 법 | **2·5·6장은 바꾸면 안 되는 것**(데이터·상태·안전 규칙), **10장은 바꿔도 되는 것**(지금 디자인), 11장은 받고 싶은 결과물 |

## 1. 한 줄 소개

화분 3개(구역 Z1·Z2·Z3)의 센서 값을 실시간으로 보여 주고, **"이 값을 믿어도 되는지, 아니면 무엇을 확인해야 하는지"**를 알려 주며, 웹에서 급수·정지·보정 명령을 보내는 앱.

핵심 아이디어는 **같은 것을 센서 두 개(A=대상, B=비교)로 재서 비교**하는 것이다. 값이 서로 어긋나거나, 급수했는데 무게는 늘고 수분은 안 오르면 "센서를 의심하라"고 알려 준다. 그냥 숫자 대시보드가 아니라 **센서 신뢰도 진단 도구**다.

## 2. 누가, 어디서, 어떻게 쓰나

| 항목 | 내용 |
|---|---|
| 사용자 | 한 팀(학생·연구 팀)이 같이 쓴다. **로그인 없음.** 주소를 아는 사람은 누구나 보고 명령을 보낼 수 있다 (주소는 팀 안에서만 공유) |
| 기기 | ① **폰 (390px 기준, 먼저 설계)** — 현장에서 화분 옆에 서서 본다 ② **노트북 (1280px 이상)** — 발표·시연용 대시보드 |
| 장소 | 인터넷 어디서나 (웹 주소, Vercel). 앱 설치 없이 폰 브라우저로 연다 |
| 자주 하는 일 | 지금 값 훑어보기 → 이상한 구역·센서 확인 → 물 주기 → 결과 확인 → (가끔) 센서 보정 |
| 상황 | 손에 흙·물이 묻어 있을 수 있다 → 큰 터치 영역, 한 손 조작. 실내 조명·창가 햇빛 → 대비 높게 |
| 언어 | **모든 문구 한국어**. 센서 이름은 역할을 같이 쓴다: "온습도 A(대상)", "온습도 B(비교)" |

## 3. 시스템이 어떻게 연결되나 (디자인에 영향을 주는 것만)

```
[ESP32 보드 Z1·Z2·Z3] ──WiFi──▶ [Supabase (클라우드 DB + 실시간)] ◀──▶ [웹앱 (폰·노트북)]
  센서 값 5초마다 올림                                              값 실시간 표시
  명령을 받아 실행하고 결과를 적음                                   명령 넣기 · 결과 기다리기
                                    (선택) [진단 서버] ── 값을 읽어 진단 결과를 적음
```

디자인에 주는 영향:
- **값은 5초마다** 바뀐다 (구역마다 따로). 값마다 "몇 초 전 값인지"가 있다.
- **구역이 끊길 수 있다** (전원·WiFi). 마지막 값이 15초(측정 주기의 3배) 넘게 안 오면 그 구역은 **끊김**.
- **웹 자체가 클라우드와 끊길 수 있다** (폰 데이터 끊김 등) → 화면 위에 표시하고 자동으로 다시 연결.
- **명령은 바로 끝나지 않는다.** 웹이 명령을 넣으면 → 보드가 가져가고 → 실행하고 → 결과를 적는다. 보통 1~2초 안이지만(실물로는 아직 안 재 봄) 보정은 몇 초, 유량 측정은 1분 넘게 걸린다. 그동안의 "기다리는 중" 상태가 화면에 필요하다 (6.4).
- **진단은 선택 기능이다.** 진단 서버가 꺼져 있으면 진단은 없고, 값 보기·급수·보정은 그대로 된다. 진단 자리에는 "진단 서버 꺼짐"을 알린다.

## 4. 구역과 센서 — 화면에 나오는 데이터

### 4.1 구역
- 구역 3개: **Z1, Z2, Z3** (화분 1개 = 구역 1개 = ESP32 1개). 구역 이름은 영문 대문자·숫자(예: Z1).
- 구역마다 보여 줄 수 있는 것: 연결 상태, 마지막 값 시각, WiFi 세기, 펌프 켜짐 여부, 오늘 급수량(n / 300mL), 보정 상태, 펌웨어 버전.
- 구역 사진 자리: 있으면 사진, 없으면 기본 그래픽 (지금 와이어프레임은 카드 위쪽에 사진 자리).

### 4.2 센서 (구역 하나에)

| 센서 (화면 이름) | 재는 것 | 값 · 단위 · 표시 형식 | 범위 (게이지·그래프) | 비고 |
|---|---|---|---|---|
| 온습도 A (대상) | 공기 온도·습도 | 온도 `23.4°C`(소수 1자리), 습도 `45%`(정수) | 온도 10~40, 습도 0~100 | SHT31 |
| 온습도 B (비교) | 같은 것을 비교용으로 | 같음 | 같음 | A와 차이를 보여 주는 것이 핵심: `B 26.1° (+2.7)` |
| 토양 A (대상) | 흙 속 수분 | **수분 지수 0~1** `0.54`(소수 2자리), 원시 전압 `1800 mV` | 0~1 | 0=공기 중, 1=물 속. 보정 전이면 기본값 기준이라 덜 정확 |
| 토양 B (비교) | 같음 | 같음 | 같음 | A와 차이 0.25 넘으면 의심 |
| 무게 | 화분 전체 무게 | `1,234.5 g`(천 단위 쉼표, 소수 1자리), 흔들림 `±0.4 g` | 0~3000 | 급수하면 늘고 증발하면 준다. **보정 전이면 g이 없고 원시값만** (`raw 94,750 · 보정 전`) |
| 펌프 | 물 주기 | 켜짐/꺼짐, 마지막 급수, 오늘 `120 / 300 mL` | — | 1회 1~50mL |
| 12V 전원 | 펌프 전원 | `12.0 V` | 9V 아래면 문제 | 아직 안 달았을 수 있음 (그러면 "미설치") |
| 누수 | 받침에 물 | 있음/없음 | — | 선택 센서 |

### 4.3 "값이 없다"의 네 가지 — 반드시 다르게 보여야 한다

| 경우 | 뜻 | 보여 주는 법 (예) |
|---|---|---|
| **미설치** | 이 보드에 그 센서를 아예 안 달았다 | 연한 회색 "미설치" (경고 아님) |
| **보정 전** | 센서는 되는데 아직 보정을 안 했다 | 파랑(정보) "보정 전" + 원시값 + [보정하기] |
| **고장/응답 없음** | 달았는데 값이 안 온다 | 빨강(고장) 또는 `--` + 이유 |
| **끊김** | 구역 전체가 안 보인다 | 회색 "마지막 값 · 3분 전" + 값 흐리게 |

값이 없으면 숫자 자리에 `--`.

### 4.4 그 밖의 데이터
- **사건 기록**: 부팅(재시작), 펌프 켜짐·꺼짐(이유·실제 mL), 펌프 거부(이유), 설정 바뀜, 사람이 남긴 메모, 진단 시작·해제.
- **그래프용 기록**: 최근 1·6·24시간 평균 (1분·5분·15분 단위). 보관은 14일.
- **명령 기록**: 넣은 명령, 상태, 결과 (6.4).

## 5. 상태 체계 — 바꾸면 안 되는 것

### 5.1 다섯 단계 (모든 화면 공통)

| 단계 | 뜻 | 지금 색 (글자 / 연한 배경 / 점) |
|---|---|---|
| 정상 (ok) | 믿어도 된다 | `#16834A` / `#E3F5EA` |
| 정보 (info) | 할 일이 있지만 문제는 아님 (보정 전, 재시작함) | `#2456D6` / `#E8EFFF` |
| 주의 (warn) | 의심스럽다, 확인해 보라 | `#B45309` / `#FFF1E0` / `#E8890C` |
| 고장 (fault) | 이 값은 믿으면 안 된다 | `#B4233A` / `#FDE8EB` / `#D6334A` |
| 끊김 (offline) | 신호가 없다 | `#6B7280` / `#EEF0F3` |

- **색만으로 구분하지 않는다.** 항상 색 + 글자("주의") + 아이콘(또는 모양)을 같이 쓴다.
- 색 값은 바꿔도 되지만 **단계의 의미·순서와 흰 배경 대비 4.5:1 이상**은 지킨다.
- 구역·화면 전체 상태는 그 안에서 **가장 나쁜 단계**를 따른다 (고장 > 주의 > 정보 > 정상, 끊김은 별도).

### 5.2 값의 신선도
- 값 옆에 "언제 값인지"를 표시한다: `2초 전`, `1분 전`.
- **30초가 넘은 값은 흐리게.** 구역이 끊기면 회색 + "마지막 값".
- 화면 맨 위에 "센서 20개 중 19개 정상 · 2초 전 갱신" 같은 요약.

### 5.3 진단 카드에 들어가는 것 (진단 서버가 줌, 웹이 지어내지 않음)

```json
{
  "code": "SHT_AB_DIFF",
  "node": "Z1",
  "sensor": "sht_b",
  "severity": "warn",
  "title": "온습도 A·B 차이가 큼",
  "detail": "B가 A보다 2.7°C 높음 (10분째)",
  "causes": ["B 센서 근처에 열원(전장함·조명)이 있음", "B 센서 고장", "A·B 높이가 다름"],
  "checks": ["A·B를 손으로 바꿔 끼워 보고 차이가 따라가는지 본다", "거치대 높이를 확인한다"],
  "since": "2026-10-23T16:40:00+09:00",
  "action": {"label": "센서 상세 보기", "to": "/zone/Z1/sensor/sht_b"}
}
```
카드 구성: 단계 배지 · 구역·센서 · "n분째" · 제목 · 한 줄 설명 · **왜 의심되나요**(원인 후보 목록) · **이렇게 확인하세요**(체크리스트, 체크하면 기록에 남음) · 버튼(있으면).

### 5.4 나올 수 있는 진단 (총 24가지, 예시 문구 길이·개수 감 잡기용)

| 대상 | 진단 | 단계 |
|---|---|---|
| 구역 | 끊김 / 재시작됨 / 메시지 빠짐(WiFi 약함) | 끊김 / 정보 / 주의 |
| 온습도 | 응답 없음 / 범위 밖 값 / **A·B 차이 큼** / 값이 멈춤 | 고장 / 고장 / 주의 / 주의 |
| 토양 | 선 빠짐·단락 / 보정 전 / **A·B 차이 큼** / **급수했는데 수분이 안 오름** / 오래 변화 없음 | 고장 / 정보 / 주의 / 주의 / 정보 |
| 무게 | 응답 없음 / 보정 전 / 흔들림 큼 / 음수 / 과부하(7kg 초과) / 이유 없이 늘어남 | 고장 / 정보 / 주의 / 주의 / 고장 / 주의 |
| 펌프 | **물이 안 도착함**(급수했는데 무게가 안 늚) / 너무 많이 들어감 / 펌프 거부됨 / 유량 보정 전 | 고장 / 주의 / 주의 / 정보 |
| 전원 | 12V 없음 / 누수 | 주의 / 고장 |

## 6. 동작 규칙 — 바꾸면 안 되는 것 (안전·신뢰)

### 6.1 모두 정지
- **모든 화면에 항상 보인다.** 한 번에 닿는 위치 (지금은 오른쪽 아래 빨간 원형 버튼).
- **확인 창 없이 즉시** 모든 구역 펌프를 끈다. 누른 뒤 결과를 짧게 알린다 ("3구역 정지 요청 보냄").

### 6.2 급수
- **1초 길게 눌러야** 실행된다 (한 번 클릭으로 급수되는 UI 금지). 누르는 동안 채워지는 표시가 필요하다.
- 양: 1~50mL (지금 슬라이더 5mL 단위). 하루 한 구역 최대 300mL. 한 번에 펌프 최대 15초.
- 보드가 저장된 **유량(mL/초)**으로 시간을 계산한다 → "10 mL · 약 4.3초 · 2.35 mL/s". **유량 보정 전이면 급수 대신 [유량 보정하기]**.
- **켜기 전 점검** 목록을 보여 준다. 웹이 마지막 값으로 미리 계산해 **안내만** 하고, 최종 판단은 보드가 한다. 순서와 문구:

  | 순서 | 점검 | 실패했을 때 보드가 주는 이유 코드 → 화면 문구(예시, 바꿔도 됨) |
  |---|---|---|
  | 1 | 펌프가 꺼져 있음 | `already_on` 이미 켜져 있어요 |
  | 2 | 꺼진 지 3초 지남 | `cooldown` 잠깐 쉬는 중이에요 (3초) |
  | 3 | 1회 1~50mL | `bad_ml` 1~50mL만 줄 수 있어요 |
  | 4 | 오늘 합계 + 이번 양 ≤ 300mL | `daily_limit` 오늘 한도(300mL)를 넘어요 |
  | 5 | 유량 보정됨 | `flow_uncal` 유량 보정이 먼저예요 |
  | 6 | 12V 전원 있음 | `no_12v` 12V 전원이 없어요 (비상정지·퓨즈) |
  | 7 | 누수 없음 | `leak` 물이 새고 있어요 |
  | 8 | 무게 센서 응답 | `scale_dead` 무게 센서가 응답하지 않아요 |

  그 밖의 거부: `busy`(보정 중), `bad_ms`. 실패 항목이 있으면 급수 버튼을 막고 이유를 보여 준다.
- **급수 중**: 진행 막대(경과/전체), 남은 초, 무게 변화(+g). 급수 버튼은 **정지 버튼으로 바뀐다.**
- **급수 결과**: "10mL 예상 → +9.6g 도착 · 정상" (물 1mL = 1g). 안 도착하면 고장 진단으로 이어진다.
- 급수 화면 맨 아래 작게: "하드웨어 비상정지 스위치가 이 화면보다 항상 우선입니다".

### 6.3 끊긴 구역
- 그 구역의 급수·보정 버튼은 **비활성**. 정지는 언제나 누를 수 있다.

### 6.4 명령의 일생 (모든 버튼이 이 상태를 가진다)

| 상태 | 뜻 | 화면 |
|---|---|---|
| 보냄 (pending) | 웹이 넣었고 보드가 아직 안 가져감 | 버튼에 작은 로딩 |
| 실행 중 (sent) | 보드가 가져가서 실행 중 | "실행 중…" (보정·유량 측정은 단계 표시) |
| 완료 (done) | 성공 | 짧은 성공 표시 + 결과 값 |
| 실패 (failed) | 보드가 거부·실패 | 이유를 사람 말로 (6.2 표) |
| 만료 (expired) | **10초 안에 보드가 안 가져가서 무효** (오래된 급수가 나중에 실행되는 사고 방지) | "구역이 응답하지 않아 취소됐어요" |

- 웹이 기다리는 시간: 기본 10초, 영점·배율 보정 15초, 유량 측정은 (펌프 시간 + 70초). 넘으면 "응답이 없어요".
- `정지`는 언제나 다른 명령보다 먼저 실행되고, 대기 중인 급수를 취소한다.

### 6.5 진단 문구
- 진단의 제목·설명·원인·확인 방법은 **진단 서버가 준 문장만** 보여 준다. 웹이 만들어 내지 않는다.
- 단, "끊김", "n초 전", "보정 전", "미설치"는 진단이 아니라 데이터 표시라서 웹이 직접 보여 준다.

## 7. 화면 목록과 필수 요소

경로는 지금 구현 기준. 화면을 합치거나 나눠도 되지만 **아래 기능은 어딘가에 모두 있어야** 한다.

### 공통 틀
- 맨 위 **상태 섬**(지금은 아이폰 Dynamic Island 모양): 한눈 상태 + 급수 진행 + 새 고장 알림. 우선순위:
  1. 클라우드 연결 끊김 → 빨간 점 "연결 끊김 · 다시 연결 중"
  2. 어느 구역이든 급수 중 → "Z1 급수 중 · 10mL" + 진행 막대 + 남은 초 + 무게 변화 + **정지**
  3. 새 고장 진단 (6초 이내) → 크게 펼쳐 제목·설명·[자세히]
  4. 주의·고장이 있음 → 가장 나쁜 것 1개 "Z1 온습도 B 주의 · +2.7°C"
  5. 그 외 → 초록 점 "3구역 연결"
  - 탭하면 구역별 요약(점 3개 + 진단 수)으로 펼침.
- 하단 메뉴 (모바일): **홈 · 진단(개수 배지) · 급수 · 기록** (+ 설정). 노트북은 위나 옆으로.
- **모두 정지** 버튼 (6.1).
- 하위 화면 헤더: 뒤로 · 제목 · (오른쪽) 관련 바로가기.

### 01 홈 `/`
- 인사·요약: "센서 20개 중 19개 정상 · 2초 전 갱신" + 진단 수 알림 버튼.
- **구역 카드 3개** (넘겨 보기): 구역 이름, 상태 배지, 온도·습도·토양·무게 4칸, 사진 자리.
- 고른 구역의 **센서 카드 목록**: 온습도 A, 온습도 B, 토양 A, 토양 B, 무게 (각각 값 + 상태 + n초 전 + 미설치/보정 전 표시).
- 펌프 카드: 12V 상태, 마지막 급수, 오늘 n/300mL, [급수].

### 02 구역 상세 `/zone/:node`
- 구역 탭 (Z1·Z2·Z3).
- **큰 원형 게이지**: 고른 지표(온도·습도·토양·무게)의 A 값 + B 위치 표시 + 차이 칩 `B 26.1° (+2.7)`.
- 지표 고르기 (4개 원형 아이콘 버튼).
- **A·B 비교** 카드: 막대 2개 + 차이 (무게는 A·B 대신 흔들림 ±g).
- 최근 1시간 미니 그래프 (A 실선, B 점선).
- [급수] 바로가기.

### 03 센서 상세 + 진단 `/zone/:node/sensor/:sensor`
- 센서 이름 + 역할 + 연결 정보(핀·주소).
- 진단이 있으면: 진단 카드(5.3) + 그래프(A·B + 허용 범위 띠) + 원인 + 확인 체크리스트 + [메모 남기기] [기록에서 보기].
- 진단이 없으면: 초록 "정상 · 믿어도 됩니다" + 지금 값 + 응답률.
- 진단 서버가 꺼져 있으면: "진단 서버가 꺼져 있어 신뢰도 판단을 못 해요" + 값은 그대로.

### 04 급수 `/water/:node`
- 구역 탭, 물 양 표시(큰 숫자 "10 mL" + "약 4.3초 · 2.35 mL/s"), 양 슬라이더(0~50, 5 단위), 켜기 전 점검 목록(6.2), **1초 길게 눌러 급수**, 급수 중 정지, 지난 급수 결과, 비상정지 안내 문구.

### 05 진단 목록 `/diagnostics`
- "지금 믿기 어려운 값 n개 · 3구역 중 m구역".
- 필터: 전체·고장·주의·정보 (개수 포함).
- 진단 카드 목록 (고장이 가장 눈에 띄게). 카드에 버튼(보정하기 등)이 있을 수 있다.
- [해결된 진단 n개 보기].
- 진단 서버가 꺼져 있으면 그 안내.

### 06 보정 마법사 `/calibrate/:node/:kind`
종류 탭: **로드셀 · 토양 · 유량**. 단계 표시(Stepper) + 단계 설명 + 지금 읽는 값 + "안정됨" 표시 + [이전] [실행]. **보드 결과가 성공이어야 다음 단계**, 실패면 이유를 보여 주고 그 단계에 남는다.

| 종류 | 단계 |
|---|---|
| 로드셀 | ① "계량판을 비우세요" → [영점 잡기] (약 2초) ② "무게를 아는 물건을 올리세요" + 무게 입력(기본 500g) + 안정되면 [보정] ③ 확인: 지금 무게가 입력값 ±2% 안이면 초록 체크 |
| 토양 (A, B 각각) | ① "센서를 공기 중에 들고 있으세요" → 지금 mV + 안정 → [저장] ② "경계선까지 물컵에 꽂으세요" → [저장] ③ 확인: 공기 − 물 ≥ 500mV면 정상, 아니면 "차이가 너무 작아요" |
| 유량 | (로드셀 보정이 먼저 필요) "출수구 아래 화분이 있어요. 10초 동안 펌프를 돌려 늘어난 무게로 유량을 잽니다" → [측정] (무게 안정 → 10초 펌프 → 최대 60초 안정 대기, **1분 넘게 걸릴 수 있음**, 진행 표시 필요) → 결과 "10초에 23.5g → 2.35 mL/s" → [저장] |

### 07 기록 `/history/:node`
- 구역 탭, 기간(1·6·24시간), 지표 칩.
- 선 그래프: A 실선, B 점선, 급수 시점 세로선 + "급수", 진단 구간 연한 띠.
- 한 줄 요약: "6시간 동안 −18.4g 증발".
- 사건 목록(급수·메모·진단 시작/해제·재시작) + [+ 메모].
- CSV 내보내기.

### 설정 `/settings`
- 클라우드 연결 상태, 구역별 연결·펌웨어 버전·WiFi 세기.
- 움직임 줄이기, 경고 소리 켜기.
- (시연용, 나중에) 가짜 보드 고장 재현 — 노트북에서 돌리는 가짜 보드 스크립트가 할 예정이라, 웹에는 안내 정도만.

### 노트북 대시보드 (≥1024px)
- 한 화면에: 제목 + 상태 섬 + 연결 정보 + 모두 정지 / 구역 카드 3개 가로 / 왼쪽 큰 그래프 + 오른쪽 진단 목록.
- 발표·시연용이라 멀리서도 읽혀야 한다.

### 빼기로 한 화면
- **08 시험 모드**(USB 원시 명령 콘솔): v2.0에서 제외. 센서 시험은 Arduino IDE 시리얼 모니터로 한다.

## 9. 문구·숫자 형식

| 항목 | 형식 | 예 |
|---|---|---|
| 온도 | 소수 1자리 °C | `23.4°C` |
| 습도 | 정수 % | `45%` |
| 토양 | 소수 2자리 (아래 작게 "수분 지수 0~1") | `0.54` |
| 무게 | 천 단위 쉼표 + 소수 1자리 g | `1,234.5 g` |
| 무게 변화 | 부호 + 소수 1자리 | `+9.6g`, `−18.4g` |
| 물 양 | 정수면 정수, 아니면 소수 1자리 mL | `10 mL`, `12.5 mL` |
| 전압 | 소수 1자리 V | `12.0 V` |
| 시간 | 상대 시간 | `2초 전`, `3분 전`, `1시간 5분` |
| 값 없음 | | `--` |

- 숫자는 자리 폭이 같은 숫자 글꼴(tabular)로 — 5초마다 바뀌어도 흔들리지 않게.
- 말투: 짧고 쉬운 해요체. 전문 용어 대신 할 일을 말한다 ("ADR 핀" 대신 "B 센서의 주소 선을 확인하세요" 수준은 진단 서버 문구가 정한다).
- 이모지 아이콘 쓰지 않는다.
